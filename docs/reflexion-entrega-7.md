# Reflexión — Entrega 7

El módulo de seguridad resuelve el ingreso sin identificación y la falta de un autor asociado a los cambios. Ahora cada persona entra con su cuenta y accede a los módulos que corresponden a su función. Las altas, modificaciones, bajas y reactivaciones quedan registradas con usuario, fecha y registro afectado. Esto permite reconstruir qué pasó ante un error y conserva la información necesaria para revisar una operación. En los datos anteriores dejamos el autor sin asignar, porque no tenemos evidencia para atribuirlos a una persona.

La protección de las contraseñas y la diferenciación de roles cumplen funciones complementarias. El hash evita almacenar la contraseña en texto legible, mientras que los permisos limitan las acciones disponibles para cada usuario. Por ejemplo, un enfermero puede registrar signos vitales, pero no emitir una prescripción ni administrar cuentas. También protegimos al último administrador activo para evitar que el sistema quede sin una cuenta capaz de gestionarlo. Estas medidas mejoran el control del práctico, aunque un sistema hospitalario real necesitaría controles adicionales sobre el archivo de datos, la infraestructura y la conservación del registro de auditoría.
